One line, at most 120 characters, in which a robot vacuum explains why it
missed a spot — entered in the make.fun bounty
[The Robot Vacuum's Funniest Excuse](https://make.fun/competitions/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2)
(slug `u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2`, $2, free entry).

The entry:

> My cliff sensors identified the rug fringe as a staircase to nowhere. I chose life.

The vacuum's own cliff sensors mistake the rug fringe for a staircase to
nowhere — so the machine, owning up to its failure, simply chooses life
over the spot. A real joke from the vacuum's world, landing in a single line.

## Run

```sh
python3 main.py
```

This writes the line verbatim to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), with no trailing
newline — 83 bytes, inside the 120-character gate.
